# FixCore — Project Documentation

Documentation repository for **FixCore**, developed by **TechMakers**, a team of Software Engineering students from the Universidad Peruana de Ciencias Aplicadas (UPC).

## Project Overview

FixCore is a web-based platform designed to improve industrial maintenance management for manufacturing SMEs, industrial service contractors, and maintenance teams.

The platform aims to centralize:

- Plant, machine, and asset management.
- Preventive maintenance planning and scheduling.
- Failure reporting and tracking.
- Work order management.
- Spare parts inventory management.
- Operational dashboards, reports, and performance indicators.

This repository contains the project's research, requirements analysis, software design, architecture, implementation documentation, and development evidence.
